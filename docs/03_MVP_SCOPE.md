# MVP Scope

## MVP objective

พิสูจน์ว่า Rise Pals สามารถเปลี่ยนความกังวลเรื่อง AI ให้เป็นเส้นทางพัฒนาที่ผู้ใช้เข้าใจ ลงมือทำ และกลับมาใช้งานต่อได้

MVP ไม่จำเป็นต้องพิสูจน์ marketplace ทั้งระบบ แต่ต้องพิสูจน์วงจรหลัก:

> Assessment → Priority Gap → First Lesson → Practice → Visible Progress

## Primary user journey

1. ผู้ใช้เข้า landing page และเข้าใจปัญหาภายในเวลาไม่นาน
2. เห็นข้อมูลอ้างอิงที่อธิบายว่าความคาดหวังในงานกำลังเปลี่ยนอย่างไร
3. เริ่ม onboarding และระบุ role/context ของตนเอง
4. ทำ baseline assessment ของ 8+2 framework
5. ได้ skill map พร้อมจุดแข็ง จุดเสี่ยง และคำแนะนำหนึ่งลำดับแรก
6. เริ่ม micro-lesson หรือ scenario แรกทันที
7. ได้ feedback, XP และ progress ที่มีความหมาย
8. เห็น next action และเหตุผลที่ควรกลับมา

## In scope

### Public experience

- Landing page
- Product explanation and evidence blocks
- Pricing placeholder or waitlist CTA
- Thai-first responsive design

### User foundation

- Account creation and sign-in
- Minimal profile: role, function, experience band, goals and consent
- Privacy-aware data handling

### Assessment

- Baseline 8+2 assessment
- Scenario-based and self-reflection question types
- Transparent progress and completion state
- Skill profile with explanatory copy
- Priority gap recommendation

### Learning loop

- Lesson catalog limited to a small validated pilot set
- Lesson player with text, visual, interaction and motion
- Practice activity and rubric-based feedback
- XP/progression tied to meaningful action
- Continue-learning state

### Proof and progress

- Skill map/history
- At least one proof artifact type
- Completion record that distinguishes viewing from demonstrated practice

### Content operations

- Versioned lesson content format
- Source/evidence metadata
- Simple internal workflow for drafting, reviewing and publishing content

### Measurement

- Privacy-conscious product analytics
- Events for assessment start/completion, lesson start/completion, practice completion and return behavior

## Out of scope for first MVP

- Full job board or applicant tracking system
- Automated hiring decisions
- Large instructor marketplace
- Native iOS/Android apps
- Complex social network or public feed
- Dozens of courses before the core loop is validated
- Enterprise administration suite
- Unvalidated “AI replacement risk score” for an individual
- Aggressive notification or purchase dark patterns

## Gamification rules

- XP ต้องให้กับ action หรือ evidence ไม่ใช่เวลาเปิดหน้าจอ
- Streak ไม่ควรลงโทษคนที่งานยุ่งจนเกิดความรู้สึกล้มเหลว
- Badge ต้องสื่อถึงสิ่งที่ผู้ใช้พิสูจน์แล้ว
- Animation ต้องช่วยอธิบาย progress, cause-and-effect หรือ feedback ไม่ใช่แค่ตกแต่ง
- Progress ต้องสะท้อนทั้งความต่อเนื่องและคุณภาพ

## MVP acceptance signals

- ผู้ใช้ทดลองเข้าใจ top gap และเหตุผลของคำแนะนำได้
- ผู้ใช้ส่วนใหญ่ที่จบ assessment เริ่มกิจกรรมแรกได้โดยไม่ต้องมีคนสอน
- ระบบบันทึก progress ได้ถูกต้องหลัง refresh/sign-in ใหม่
- Lesson แรกมี practice และ feedback ที่ใช้งานได้จริง
- ทุก external evidence claim มี source metadata
- UI ใช้งานได้บน mobile และ desktop พร้อมพื้นฐาน accessibility
